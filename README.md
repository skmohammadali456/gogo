# GOGO Programming Language

GOGO is a Go-powered programming language designed for building modern frontend and UI applications with an easy, multilingual grammar and a TypeScript-class type system.

## Project Status

GOGO 1.0 is being developed in 62 controlled steps.

Current step: Foundation

See `PROJECT_STATUS.md` and `roadmap/GOGO-1.0-62-Steps.md` for the development plan.
